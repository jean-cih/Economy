# 📚 Экономика и инвестиции: Личная база знаний

Добро пожаловать в мой репозиторий! Здесь собрана структурированная база знаний по экономике, макроэкономике и финансовым рынкам. 

Этот проект создан как личный справочник и учебное пособие, в котором я аккумулирую теорию, аналитику и практические материалы, необходимые для понимания экономических процессов и инвестирования.

## 🗂 Структура репозитория

Материалы организованы по тематическим папкам и файлам. Ниже приведено краткое описание того, что вы найдете внутри:

### 📈 Финансовые инструменты
Подробные материалы по различным классам активов:
*   **Акции** — анализ, оценка, особенности торговли.
*   **Облигации** — виды, доходность, риски.
*   **Опционы** — стратегии и основы деривативов.
*   **Фонды** — ПИФы, ETF и другие формы коллективного инвестирования.
*   **Фьючерсы** — механизмы работы срочного рынка.

### 🌍 Макроэкономика и аналитика
Раздел для понимания глобальных и локальных экономических процессов:
*   **Аналитика** и **Сектора экономики** — обзоры и исследования.
*   **Экономические циклы** — теория и практика.
*   **Ключевые показатели:** ВВП, Инфляция, УТМ (Уровень трудовой миграции/мобильности), Дюрация.
*   **Рынок:** Индексы российского фондового рынка.
*   **Методология:** Классификация акций, Мультипликаторы, Контр- и проциклическая политика, Уровень деловой и инвестиционной активности.

### 📖 Книги и обучение
Библиотека фундаментальных знаний:
*   **Азбука инвестора** — база для начинающих.
*   **Б. Грэм "Разумный инвестор"** — классика стоимостного инвестирования.
*   **Маккена Д. и др. "Твой первый миллион"** — практические советы.
*   **Экономика для "ЧАЙНИКОВ"** — просто о сложном.
*   **МЕТОД** — конспекты.

### 📝 Заметки и файлы
*   **Налоги** — важная информация по налоговому законодательству и вычетам.

## 🎯 Цель репозитория
Систематизировать знания, чтобы иметь быстрый доступ к нужной информации по экономике и финансам, а также отслеживать собственный прогресс в обучении.

## 🛠 Как использовать
Вы можете свободно изучать материалы, использовать их для самообразования или как шпаргалку при принятии инвестиционных решений. Все файлы находятся в открытом доступе.
